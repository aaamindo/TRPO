# Описание проекта

## 1. Назначение проекта

Наш проект — это создание информационного сайта с использованием HTML. Сайт предназначен для представления информации, оформления главной страницы и предоставления посетителям сведений о разработчиках проекта.

На сайте будут размещены:
- **Главная страница (`index.html`)** — содержит название сайта, изображение и основную информацию.
- **Страница контактов (`contact.html`)** — содержит адрес и номер телефона.
- **Страница о разработчиках (`about.html`)** — содержит фотографии, ФИО и возраст участников команды.

## 3. Используемые технологии

Для разработки проекта используется язык разметки HTML, который позволяет создавать структуру веб-страниц и размещать на них текст, изображения и другую информацию.

## 4. Результат работы

В результате выполнения проекта будет создан сайт, состоящий из нескольких HTML-файлов. Каждый участник команды отвечает за свою часть работы. Совместная работа позволит объединить все страницы в единый проект.
